# Взаимодействия v0.4 · правила сохранения 6

18 сентября 2026. Реализованы этапы A–C из [спецификации](isaac-mechanics-spec.md) в `feat/minimal-vector`. Новый спуск использует правила 6; старые сохранения продолжаются без миграции правил. Числа врагов не менялись. Графика остаётся SVG/CSS, композиция — из Figma-ветки.

## Что меняет решение

| Находка | Новое решение | Цена / ограничение |
|---|---|---|
| Кольцевая скоба | Искать группы через противоположные края | Работает с 3+/4+, полями 5/6/7; бомбы не переходят край |
| Резак по линейке | Горизонталь против отряда, вертикаль против блока, пересечение для основной цели | Горизонталь 60% всем, вертикаль 100% с пробиванием, пересечение 100% + 30% остальным |
| Зеркальная подпись | Подготовить первую группу 4+ оружия внутри оплаченного действия | Повтор 50%, исходные цели; погибшая цель не заменяется |
| Бракованная копия | Спланировать третью группу первой волны ручных сдвигов | 40% синтетического удара из трёх клинков, без геометрии и модификаторов фишек |
| Пепельный реестр | Разрушать нужные соседние фишки, а не только собирать | Половина базового клинка/щита вниз, два ресурса → один; остатки только внутри действия |
| Кассовый молоток | Добить с избытком ради денег | −2 к пакету; избыток после блока, максимум 5 монет на исходного врага; призыв/копии не платят |
| Залоговый пояс | Купить сохранение здоровья или оставить деньги лавке | 2 монеты за HP, максимум 4 HP за ход; только внешний урон после блока; теряется прежний бонус штанов |
| Куртка курьера | Чередовать строки и столбцы | Первая смена оси −1 ОД, минимум 1; теряется прежний бонус одежды |

Навыки по-прежнему занимают два слота и стоят 1 ОД плюс ресурс. **Оттиск** (4 энергии) повторяет 60% записанного первичного оружейного пакета по текущим живым целям; новое оружие не меняет запись. **Разрыв строки** (4 фокуса) разрушает выбранную строку, запускает местные бомбы и каскады; сами уничтоженные фишки не являются матчем. **Отсрочка** (5 энергии) сохраняет следующее действие врага и пропускает один ответ; один раз на врага, яд и смена фазы продолжаются. При смене фазы отсрочка отменяется, новый замысел виден заранее.

Призма начисляет 2/1/1 за первые три каскада ручного сдвига; первая волна не каскад. Лампа один раз за ход даёт `4 + min(4, потерянная энергия)` при реальном переливе. Обратная тяга складывает фактические оплаты энергией; на шести заряжает +3 блока следующей группе щитов один раз за ход.

## Предложения и маршрут

Обычная награда сохраняет слот экипировки/численного улучшения; второй слот распределяет преобразующие возможности среди приёмов, модификаторов, реликвий и типов снаряжения. Это случайный выбор, а не поиск недостающей части сборки. Зависимости описываются возможностями (яд, разрушение, оплата энергией/здоровьем). Поведенческая броня не отсекается по меньшему bonus.

Неизвестная соседняя дверь даёт неполную подсказку из уже сохранённого узла: шаги/много шагов, механизм, тихая комната или следы. Дополнительно видны признаки большой схватки дальше по ветви; отсутствие признаков не обещает безопасность. UI и WebMCP используют один публичный вид карты, без раскрытия состава и предметов.

В двух существующих лавках мастерская предлагает два сохранённых случайных других типа оружия за 28 монет. Качество на момент покупки сохраняется, в том числе после заточки в этом визите. Одна переделка за визит, альтернативы не перегенерируются при чтении/загрузке.

На ранних элитных узлах комнат 4/14 контракт принимается до первого действия. Победа не позднее третьего ответа врагов даёт ещё 15 монет. Базовая награда и её RNG не меняются, штрафа за отказ/невыполнение нет. Это счётчик ответов, не таймер реального времени.

## Контракты движка

- `match-rules.ts`: общая геометрия для поиска ходов, предпросмотра, генератора и разрешения; старый `groups` остаётся адаптером.
- `combat-events.ts`: профиль и пакет атаки, зафиксированные цели, масштабирование копий, валидация. Копии наследуют попадание/яд/пробивание, но не начисление за группу и не создают копий себя.
- `effectState`: последние 80 событий с корневым действием, родителем, причиной, источником, волной и областью ограничений. Запись оружия и счётчик спутника живут внутри комнаты, оплата и страховка — внутри хода.
- Предпросмотры работают на копиях состояния. Прогноз ответа для пояса возвращает только потери HP/монет и признак поражения, а не будущую доску.
- WebMCP: `accept_contract`, `buy_workshop`, `toggle_insurance`; состояние содержит те же возможности, прогноз и предложения, что UI.
- Восемь замороженных трасс правил 5 сравнивают результаты вместе с кадрами и RNG по SHA256. Исторические тесты растров проверяют сохранённые исходники; действующая векторная отрисовка проверяет весь каталог, включая новые вещи.

## Граница этой поставки

Этап D не начат: перевёрнутая гравитация, промокашка, шлем наблюдателя, печать возврата, грязная правка и новые герои ждут наблюдений за первой партией. Не добавлены звук, новые биомы или численные усиления врагов.

Проверка интереса и удержания **не проведена**. Подготовленные сильные маршруты нужны для целостности переходов и сохранений, а не измерения баланса. Сценарии добавлены в существующий [playtest-v02.md](playtest-v02.md). Следующая продуктовая проверка — способен ли человек показать изменившееся решение и добровольно захотеть другой забег.

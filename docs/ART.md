# Осколки — арт-контракт

Анимированный пиксель-арт. Стерильный серо-зелёный офис и его тёмная изнанка: холодные лампы, красный аварийный свет, зелёные мониторы. Эталоны стиля — `render/art/heroes.ts` (Стажёр, 56×96), `render/art/cast-office.ts` (молодые коллеги) и `render/art/env-openspace.ts` (офисный набор).

## Масштаб

- Внутреннее разрешение подбирается под экран (640×360 на 16:9, 512×384 на iPad, ~290×630 на телефоне) и всегда масштабируется целым числом: в 1080p пиксель спрайта — ровно 3×3 пикселя экрана.
- Всё рисуется в целых координатах, без поворотов и дробного масштаба. Исключение — иконки фишек на крупных клетках телефона: ровно ×2. Крупный текст — отдельный пиксельный шрифт (`render/art/font-big.ts`), а не растянутый мелкий.
- Размеры (версия 3, 24.09.2026: крупные персонажи в низких комнатах):

  | Объект | Размер |
  |---|---|
  | Герой | холст 56×96, фигура ≈ 88 px от пяток до макушки (≈ 3,6 головы, голова с волосами 23–25 px), ox 28, oy 95 |
  | Взрослый NPC | 84–90 px ростом; сидя: сиденье стула 30 px над полом, столешница 40, макушка 75–78 |
  | Мелкий враг | 36–56 в высоту |
  | Средний враг | 60–90 |
  | Крупный враг | 90–120 |
  | Босс | 120–150 в высоту, до 150 в ширину (почти упирается в потолок) |
  | Иконка фишки | 18×18 |
  | Иконка предмета | 16×16 |
  | Иконка HUD | 9×9 |

- **Сцена** — низкая комната: пол (линия ног) на y = 172 при высоте экрана 360, потолок на ≈150 px выше пола, сверху видна полоса подвесного потолка с лампами. Поле фишек — внизу экрана, под сценой.
- Пропорции предметов от роста героя: перегородка кабинки ≈ 58 px (по грудь), дверь ≈ 104×56, стол 40, кулер ≈ 72, копир ≈ 60×64, торговый автомат ≈ 110×56, картотека ≈ 76, плакат ≈ 40×54.
- В первом биоме окон нет: кладовая бумаг, которая тянется без конца. Внутри биома несколько локаций из одного набора (кабинки, копировальная, склад, комната отдыха, коридор, архив) — переходят друг в друга естественно.

## Формат

Спрайт — объект `SpriteDef` из `render/sprite.ts`:

```ts
export const ENEMIES_FLOOR1: Record<string, SpriteDef> = {
  rat: {
    w: 20, h: 14,
    legend: { '.': '', k: 'ink0', g: 'grey3', /* … */ },
    frames: { idle0: [...rows], idle1: [...], attack: [...], hurt: [...] },
    ox: 10, oy: 13, // точка опоры: центр по X, нижняя строка (ноги)
  },
};
```

- Каждая строка ровно `w` символов, строк ровно `h`. Символ `.` — прозрачность.
- В `legend` — только имена из `render/palette.ts` (`PAL`).
- Проверка: `node scripts/sprite-sheet.mjs render/art/<файл>.ts output/sprites/<файл>.png 4`. Скрипт печатает ошибки длины строк и неизвестные символы.

## Правила рисунка

1. **Контур:** внешний, 1 px, почти чёрный (`ink0`). Внутри силуэта линии не чёрные, а самого тёмного тона материала (цветной контур). Светящиеся части контур могут перекрывать.
2. **Свет:**
   - тёплый ключевой свет сверху слева (лампы, огонь): блики на верхне-левых гранях — `skin3`, `cream`, `gold4`, `orange4`, `paper`;
   - холодный контровой свет справа (окна, дождь): 1 px акцента по правым краям — `cold4`, `cold5`, `teal4`;
   - тени к низу и вправо уходят в холодное (`cold1`, `ink3`, `vio1`), а не в чёрное. Отсюда контраст.
3. **Тона:** 3–4 на материал плюс блик, крупные цветовые пятна. Без шума, одиночных точек и «подушечного» затенения от краёв к центру. Сглаживание — только промежуточным тоном на длинных дугах.
4. **Материалы:**

   | Материал | Рампа |
   |---|---|
   | Бумага | `cream` → `paper` → `paper2` → `grey3` |
   | Металл | `white` → `grey4` → `grey3` → `grey2` → `grey1` |
   | Дерево | `wood4` → `wood3` → `wood2` → `wood1` |
   | Чернила | `vio5` → `vio4` → `vio3` → `vio2` → `vio1` |
   | Огонь | `cream` → `gold4` → `orange3` → `orange2` → `red2` |
   | Вода | `teal5` → `teal4` → `teal3` → `teal2` → `teal1` |
   | Кожа | `skin3` → `skin2` → `skin1` → `skin0` |

5. **Светящиеся детали** (глаза, лампы, угли, фитили) — яркие тёплые цвета. В игре они получат ореол.
6. **Направление взгляда:** герой смотрит вправо, враги — влево, на героя.
7. **Кадры героя:**

   | Кадр | Что показывает |
   |---|---|
   | `idle0`, `idle1` | дыхание: плечи и голова на 1 px |
   | `walk0`–`walk3` | шаг вправо: контакт, проход, контакт другой ногой, проход |
   | `windup` | замах перед ударом: корпус назад, рука с оружием отведена |
   | `attack` | удар вправо, максимальный вынос |
   | `hurt` | отброшен влево, зажмурился |
   | `block` | принял удар бронёй: стойка, руки перед собой, холодный блик |
   | `hold` | обеими руками поднимает над головой найденный предмет (сам предмет рисует игра ≈ 88 px над полом) |
   | `sit0`, `sit1`, `sleep`, `wake` | за столом: печатает; спит лицом в бумагах; проснулся, очки набок (все трое) |
   | `carry0`–`carry3`, `look`, `reach`, `kneel`, `grab` | только Стажёр, для вступления: несёт стопку, оглядывается, тянется к выключателю, ставит стопку, хватает нож |

   Сидячая раскладка общая для героев и коллег: сиденье стула 30 px над полом, столешница 40 px, спина на ox − 26.

8. **Кадры врага:**

   | Кадр | Что показывает |
   |---|---|
   | `idle0`, `idle1` | дыхание или покачивание, сдвиг на 1 px или моргание |
   | `windup` | подготовка: отклонился назад, поднял оружие или лапу, глаза вспыхнули. Показывается перед каждым действием — силуэт должен заметно отличаться от `idle` |
   | `attack` | выпад влево, пасть открыта, максимальный вынос |
   | `hurt` | отдача вправо, зажмуренные глаза |

   Дополнительные кадры — где их требует механика: `sub` (угорь под водой), `shine` (зеркало блестит), `phase2` и `phase2b` (босс во второй фазе, пара кадров покоя).

9. **Узнаваемость:** силуэт читается в 1×, кадры `idle` → `windup` → `attack` различимы по одному силуэту. Никакого текста внутри спрайта.

**Люди в офисе.** Без имён — ни над репликами, ни в тексте. Часть — с образом (лицо, одежда, свой предмет на столе), часть — безликие силуэты цвета тени. Коллеги в основном молодые (20–30), лица приятные: крупная голова, живые глаза с бликом, мягкие черты; жуть — в изнанке (враги-двойники вроде Соседа), а не в офисных людях. Среди коллег есть молодая красивая девушка (`npc_girl`). Занятые кабинки офиса рисуются кадрами `os_cubicle` `open0/open1` — без спинки стула над перегородкой.

Сцена собирается в `render/stage.ts`: у каждого отдела три локации и комната босса (1-й: кабинки, копировальная, склад, комната отдыха, коридор, стеклянный кабинет; 2-й: стеллажи, читальный зал, насосная, хранилище; 3-й: топочная, раздевалка, щитовая, комната зеркал; 4-й: приёмная, переговорная, библиотека, кабинет цензора). Соседние узлы карты тяготеют к одной локации, касса и кулер — в «бытовых» комнатах.

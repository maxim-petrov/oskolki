## Методика

- Боты (`game/bot.ts`): жадный выбирает ход по оценке первой волны, берёт вещи по таблице ценности (`GEAR_SCORE`) и меняет их в бою, если так заметно лучше, ходит по карте с оглядкой на здоровье. Это нижняя граница умения игрока: живой игрок сильнее.
- Забеги: сиды 1…N, одинаковые для всех вариантов — сравнения парные (одни и те же карты, одни и те же развилки, пока решения не разойдутся).
- Лаборатория: из забегов жадного бота берутся реальные сборки перед каждым боем (вещи, предметы, здоровье) — Изнанка отдела: 2413, Затопленный архив: 1702, Котельная: 1082, Дирекция: 447. В лаборатории бой переигрывается с изменением сборки и тем же сидом.
- «± N» — стандартная ошибка; разница меньше двух ошибок — шум.
- Размеры выборок: забеги 400, другие политики 200, герои 200, предметы 200, вещи 160, сборок на отдел в лаборатории 40, на встречу 36.

# Дворец слов — Селеста

Семнадцатая самостоятельная тема, `palace-summit`, расположена после «Дворец слов — подвал» в переключателе оформления. Выбор сохраняется в браузере через существующий механизм тем.

## Оформление

Рисунки, шрифт, размеры и формы «Дворца слов» сочетаются с палитрой существующей темы «Вершина», вдохновлённой Celeste: ночное синее поле, белые рамки, ледяной голубой, сиреневый и коралловый акценты. Основные действия выделены коралловым, выбранная тема — светлым сиреневым с тёмным текстом.

Цветовые правила находятся в `app/palace-summit.css`; геометрия и адаптивность наследуются из `app/palace.css`. Бой, меню, настройки, награды и подсказки используют общую палитру.

Исходные изображения `public/art/pronoun-palace/` используются без изменения файлов. При показе применяется цветокоррекция:

- Улица: `sepia(1) hue-rotate(175deg) saturate(1.7) brightness(.62)` — холодные ночные оттенки.
- Персонажи: `saturate(1.25) brightness(1.08)` — немного ярче на тёмном фоне.
- Значки: `saturate(1.15) brightness(1.06)`.

Позы, опорные точки и анимация сохраняются. Новая генерация изображений не требовалась. Тема доступна также через существующий инструмент WebMCP смены оформления.

## Проверка

Проверка типов, линтер и производственная сборка прошли. Локальная страница отвечает HTTP 200. Реестр содержит 17 уникальных тем, все пути к фонам существуют.

Сравнение с предыдущим коммитом подтвердило неизменность исходных изображений «Дворца слов», компонентов его персонажей и значков, темы «Вершина», предыдущих вариантов дворца, игровых правил, анимации и настроек размещения. В общем `palace.css` расширена только область применения селекторов.

Браузерное тестирование и игровые ходы в этой итерации не выполнялись.

Локальная игра: http://localhost:4531/. Публикация не выполнялась.

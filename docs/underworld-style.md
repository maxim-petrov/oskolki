# Подземный мир

Восьмое оформление «Осколков», вдохновлённое предоставленными скриншотами Hades. Античный зал, зелёный огонь, золото на угольных панелях, алые ткани, кремовая типографика и рисованные предметы. Геометрия поля и правила остаются прежними.

## Рисунки

Три оригинальных изображения созданы через image_gen одной параллельной серией. Персонажи, предметы и окружение нарисованы специально для прототипа; игровые ассеты, код, логотипы и персонажи Hades не заимствованы. Полные промпты записаны в [underworld-prompts.json](underworld-prompts.json).

| Файл                               | Содержание                                                       | Размер            |
| ---------------------------------- | ---------------------------------------------------------------- | ----------------- |
| `public/art/underworld/actors.png` | Воин с огненным мечом и щитом, страж с нефритовым копьём; 12 поз | 1024 × 1536, RGBA |
| `public/art/underworld/arena.png`  | Античный зал с колоннами, лавой и зелёными жаровнями             | 1672 × 941, RGB   |
| `public/art/underworld/icons.png`  | 12 предметов для фишек, ресурсов и интерфейса                    | 1448 × 1086, RGBA |

PNG сохранены побайтно без изменений. Исходные SHA-256, границы элементов и измерения прозрачности находятся в [underworld-atlas.json](underworld-atlas.json); проверка масок — в [underworld-clipping.json](underworld-clipping.json).

## Подключение

- ID оформления: `underworld`, название: «Подземный мир». Выбор сохраняется прежним провайдером отдельно от забега.
- `components/underworld-actor-art.tsx`: шесть поз для каждой стороны — idle, windup, strike, guard, hurt, death. У всех кадров одинаковый масштаб исходника и общий уровень ног. Длинные меч и копьё выходят за номинальную область спрайта, не уменьшая тело.
- SVG выделяет измеренные области исходного атласа. Три небольшие маски убирают только части соседних кадров, попавшие в прямоугольник. Проверка на нескольких порогах альфа-канала не нашла потерь собственных пикселей.
- Альфа-перенос в SVG убирает слабую дымку экспорта ниже 8/255 и сохраняет мягкие края рисунка. Растровый исходник не редактируется.
- `components/underworld-icon.tsx`: отдельная область для каждого предмета с запасом под эффекты. Предметы остаются различимыми благодаря четырём цветам ячеек.
- `app/underworld.css`: все правила ограничены `html[data-skin='underworld']`, включая меню, настройки, награды, магазин, маршрут, достижения, испытание и окончание забега. Используются уже подключённый локальный Nunito и системный Georgia.
- Новые позы исполняет существующая последовательность анимации. Типы событий, правила и случайная последовательность не менялись.

Это прототипная смена нарисованных поз, не скелетная анимация. Все типы врагов используют одного нового стража; имя, намерение и здоровье показываются отдельно для каждой цели.

## Проверка

В браузере проверены все 12 поз и 12 предметов на временной странице атласа; страница удалена перед сборкой. На отдельном тестовом origin проверены бой с двумя врагами, фишки, награды, событие и маршрут. Мобильный экран 390 × 844 не имеет горизонтальной прокрутки.

Переключение всех восьми оформлений проверено через публичный интерфейс игры с сопоставлением состояния до и после. Состояние пользовательского победного забега совпало во всех восьми случаях и после перезагрузки; выбранный «Подземный мир» восстановился. В тестовом бою проверены сдвиги, ответ двух врагов, потеря здоровья, получение блока и урон от реликвии. Мобильный диалог настроек проверен визуально.

Прошли все 29 тестов `npm test`, `npx tsc --noEmit`, `npm run lint`, `npm run build` и `git diff --check`. SHA-256 трёх PNG совпали с исходниками. Временная страница атласа не входит в сборку.

Локальный адрес — http://localhost:4531; эта версия не публиковалась.

# Осколки

Пиксельный рогалик-колодостроитель про бесконечный офис компании «Цельность». Стажёр несёт стопку бумаг в архив — свет гаснет, бумаги собираются в монстра. Каждая смена — спуск по отделам изнанки офиса по плану эвакуации (карта с развилками, как в Slay the Spire). Колода — это фишки на поле 6×6: обмен двух соседних фишек, собирающий три в ряд, — ход; все фишки хода складываются в «УРОН × МНОЖ» и бьют одним ударом, как в Balatro. Смерть — не конец: стажёр просыпается лицом в бумагах за своим столом, а офис понемногу меняется.

## Запуск

```sh
npm install
npm run dev   # http://localhost:4531
```

Картинка всегда пиксель-в-пиксель: внутреннее разрешение подбирается под экран (640×360 на 16:9 — ровно ×3 в 1080p, 512×384 на iPad, ~290×630 на iPhone в портрете) и масштабируется целым числом. F — полный экран, Esc — пауза, F2 — лаборатория света.

Параметры адреса для проверки: `?play` — сразу смена, `?seed=N` — смена с сидом, `?hub` — офис, `?intro` — вступление.

## Управление

| Где | Мышь / тач | Клавиатура |
|---|---|---|
| Бой | потянуть фишку на соседнюю клетку или тапнуть две соседние; наведение или долгое нажатие на фишку — её правило; клик по врагу — цель | стрелки — курсор, Shift+стрелка — обмен, пробел — взять фишку, Q — навык, 1–5 — карманы, Tab — цель |
| Карта | клик по узлу (на телефоне: касание — что там, второе касание — идти) | — |
| Офис | клик — идти туда, клик по предмету — подойти и использовать; на телефоне кнопки ◀ ▶ и «действие» | A/D или ←/→, E — действие |

## Устройство

- `game/` — детерминированный движок: колода и мешок фишек, поле, бой с подсчётом «урон × множ», враги, карта отдела, забег, события. `npm test` проверяет правила, `npm run sim [забегов] [политика]` гоняет ботов и печатает баланс.
- `render/` — отрисовка на canvas: раскладки под экран (`view.ts`), сцена-комната из офисного набора со ступенчатым светом (`stage.ts`), бой (`combatview.ts`), смена и экраны между боями (`runview.ts`, `runscreens.ts`, `mapview.ts`), офис (`hub.ts`), вступление (`intro.ts`), процедурный звук.
- `render/art/` — пиксельные спрайты текстом. Превью: `node scripts/sprite-sheet.mjs render/art/<файл>.ts`.
- [Геймдизайн](docs/GDD.md) · [Арт-контракт](docs/ART.md).

Прежние версии ядра — в git-тегах `core/*` (последняя до офисной версии — `core/rebirth-isaac`: комнаты как в Isaac, сердца).

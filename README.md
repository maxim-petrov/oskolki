# Осколки

Пиксельный рогалик про бесконечный офис. Меняешь местами соседние фишки на поле 6×6, собираешь тройки — это ход. Враги показывают, что и когда сделают. Этажи состоят из комнат, как в The Binding of Isaac: сокровищницы, магазин, секреты, сделки за здоровье, боссы. Находки переписывают правила поля: края склеиваются, щиты бьют, ракеты летят крестом.

## Запуск

```sh
npm install
npm run dev   # http://localhost:4531
```

F — полный экран, в 1080p картинка масштабируется ровно ×3. M — звук, Esc — пауза. F2 — лаборатория света: ползунки вида света, значения сохраняются в браузере.

## Управление

| Где | Действие |
|---|---|
| Бой | потянуть фишку на соседнюю клетку или кликнуть две соседние; обмен, который собирает 3 в ряд или трогает особую фишку, — ход |
| Бой | клик по врагу — цель; клик по активному предмету или Q — применить; бомба (E) — взрыв 3×3 |
| Бой, клавиатура | стрелки — курсор, Shift+стрелка — обмен с соседкой, пробел — взять фишку, Tab — следующая цель |
| Вне боя | стрелки или клик по двери — в соседнюю комнату; клик по пьедесталу — взять предмет; Пробел — взять или спуститься в люк |
| Вне боя | бомба у стены (E, затем стрелка) — вдруг там секретная комната |

## Устройство

- `game/` — детерминированный движок: поле, бой, враги, предметы, генерация этажей, забег. `npm test` проверяет правила, `npm run sim` гоняет ботов и печатает баланс.
- `render/` — отрисовка на canvas 640×360: свет ступенями с пиксельным швом, дождь, искры, дым, мерцание ламп, постановка ходов врагов, анимация событий движка, интерфейс и процедурный звук.
- `render/art/` — пиксельные спрайты текстом. Превью: `node scripts/sprite-sheet.mjs render/art/<файл>.ts`; примерка в комнате: `node scripts/sprite-scene.mjs <скриншот> <выход.png> <файл>:<id>:<кадр>@<x>,<y>`.
